Web Application Security Assessment Lab💜🎀

//About This Project

This is my first cybersecurity project, created as part of my
self-learning journey. I built and tested this lab in my own time
to gain practical experience in web application security.

>>>Tools Used
- Kali Linux
- Docker
- OWASP Juice Shop
- Burp Suite Community Edition
- Nmap

>>>Project Objective

To learn the basic process of assessing a web application in a
safe and controlled local environment.

>>>What I Learned
- Basic web reconnaissance
- Nmap scanning
- HTTP request and response analysis
- Burp Suite Proxy
- Web application security concepts
- Documenting security findings

[Lab Environment]

The testing was performed on my own local cybersecurity lab using
OWASP Juice Shop as the intentionally vulnerable target.

Status🫶

🚧 Beginner project — currently learning and improving.
